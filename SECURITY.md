# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** using GitHub's [private vulnerability reporting](https://github.com/lermajonathan/pance-ds/security/advisories/new). Do not open a public issue.

Include the affected package (`@pance/react` or `@pance/tokens`), the version, and steps to reproduce. You will get an acknowledgement as soon as the maintainer can, normally within a week. Pance is maintained by one person, so timelines are best effort.

## Supported versions

Only the latest minor release of `@pance/react` and `@pance/tokens` receives fixes. The removal policy is in [docs/deprecation.md](docs/deprecation.md).

## Supply chain

Packages are published from GitHub Actions with npm provenance (trusted publishing). No npm token is stored in the repository.
