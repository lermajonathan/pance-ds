# DDR-DS-013: Deprecation takes two minor releases and 90 days

- **Status:** Accepted
- **Date:** 2026-10-15
- **Owner:** Design (Jonathan Lerma)

## Decision

A public API is deprecated for at least two minor releases and 90 days before removal, and removal is a major release.

## Consequences

Public API means exported components, props, tokens and CSS variables. See `docs/deprecation.md`.
