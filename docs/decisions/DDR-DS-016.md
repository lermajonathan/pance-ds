# DDR-DS-016: One Figma page per component

- **Status:** Accepted
- **Date:** 2026-10-16
- **Owner:** Design (Jonathan Lerma)

## Decision

Each component has its own Figma page with a header (name, status, version, docs link), Examples, Components (every variant) and Tokens (resolved from the repo). Pages are grouped by separators and sorted alphabetically.

## Consequences

The old single Components canvas is gone. New components start from the templates in the Doc templates page. Token tables are regenerated from the repo, not typed.
