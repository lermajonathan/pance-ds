# DDR-DS-005: Heading 3 is 20px

- **Status:** Accepted
- **Date:** 2026-10-14
- **Owner:** Design (Jonathan Lerma)

## Decision

`typography.h3` is 20px, the value the Title component ships. Modals and drawers keep 18px through `typography.h3-compact`.

## Consequences

The type-scale table in the docs follows the tokens. Figma has both `typography/h3` and `typography/h3-compact`.
