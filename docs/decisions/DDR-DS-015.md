# DDR-DS-015: The Figma Code Connect map is kept by hand

- **Status:** Accepted
- **Date:** 2026-10-15
- **Owner:** Design (Jonathan Lerma)

## Decision

Code Connect is not available on the current Figma plan, so the Figma-to-code map lives in `docs/figma-code-map.md` and is updated with each component change.

## Consequences

Revisit when the plan changes. Until then every new Figma component needs a row in the map.
